Introduction to OOP
OOP (Object-Oriented Programming) is a programming approach based on Classes and Objects.

It helps us write code that is:
- Reusable
- Organized
- Easy to maintain
- Easy to understand
Dart is an object-oriented programming language.
Four main pillars of OOP
Pillar	Meaning
Encapsulation	Wrapping data and methods together and controlling access
Inheritance	Acquiring properties and methods from another class
Polymorphism	One interface, different implementations
Abstraction	Hiding implementation details and exposing essential features

We'll study each pillar separately.

2. Class in Dart
Theory:

A Class is a blueprint or template used to create objects.

It defines the properties (variables) and behaviours (methods) that its objects can have.

Syntax:
class ClassName {
  // Properties

  // Methods
}


Example:
class Student {
  String name = "Arpita";
  int age = 22;

  void display() {
    print("Name: $name");
    print("Age: $age");
  }
}


Here:
- Student is the class name.
- name and age are properties.
- display() is a method.
Notice that we have only created a class. We haven't created an object yet.

3. Object in Dart
Theory:

An Object is an instance of a class.

We create objects to access the properties and methods defined inside a class.

Syntax:
ClassName objectName = ClassName();


Example:
class Student {
  String name = "Arpita";
  int age = 22;

  void display() {
    print("Name: $name");
    print("Age: $age");
  }
}

void main() {
  Student s1 = Student();

  s1.display();
}


Output:
Name: Arpita
Age: 22


Explanation
Student s1 = Student();


- Student – Class name.
- s1 – Object name.
- Student() – Creates an instance of the Student class.
s1.display();


Calls the display() method using the object.

Similarly, you can access properties:
print(s1.name);
print(s1.age);


4. Multiple Objects
We can create multiple objects from the same class.

Each object can have its own property values.

Example:
class Student {
  String name = "";
  int age = 0;

  void display() {
    print("Name: $name");
    print("Age: $age");
  }
}

void main() {
  Student s1 = Student();
  s1.name = "Arpita";
  s1.age = 22;

  Student s2 = Student();
  s2.name = "Divya";
  s2.age = 21;

  s1.display();
  s2.display();
}


Output:
Name: Arpita
Age: 22

Name: Divya
Age: 21


Understanding Class and Objects visually
Student
Class – Blueprint
Properties: name, age

Method: display()


Object s1

Arpita, 22


Object s2

Divya, 21




5. this Keyword
Theory:

this refers to the current object of a class.

It is commonly used when instance variables and method parameters have the same names.

Example:
class Student {
  String name = "";
  int age = 0;

  void setData(String name, int age) {
    this.name = name;
    this.age = age;
  }

  void display() {
    print(name);
    print(age);
  }
}

void main() {
  Student s1 = Student();

  s1.setData("Arpita", 22);
  s1.display();
}


Output:
Arpita
22


Understand this line:
this.name = name;


- this.name refers to the class property.
- name refers to the method parameter.
This helps distinguish between them.

6. Constructor in Dart
Very important for interviews
Theory:

A Constructor is a special method that is automatically called when an object of a class is created.

It is mainly used to initialize object properties.
Syntax
class ClassName {
  ClassName() {
    // Initialization code
  }
}


Example
class Student {
  String name = "";
  int age = 0;

  Student() {
    print("Constructor called");
  }
}

void main() {
  Student s1 = Student();
}


Output:
Constructor called


Notice:
Student s1 = Student();


As soon as the object is created, the constructor executes automatically.
Parameterized Constructor
A constructor can accept parameters to initialize object properties.
class Student {
  String name;
  int age;

  Student(String name, int age) {
    this.name = name;
    this.age = age;
  }

  void display() {
    print("Name: $name");
    print("Age: $age");
  }
}

void main() {
  Student s1 = Student("Arpita", 22);
  s1.display();

  Student s2 = Student("Divya", 21);
  s2.display();
}


Output:
Name: Arpita
Age: 22
Name: Divya
Age: 21
